# AI/ML Internship – Week 1: Breast Cancer Diagnosis Classifier

## Objective

This project is my Week 1 submission for the Advance Soft Logics AI/Machine
Learning internship track. The goal is to complete a beginner end-to-end
machine learning workflow: load a public dataset, explore and clean it,
train a baseline model, evaluate it, and document the results.

## Dataset

**Breast Cancer Wisconsin (Diagnostic) Dataset** — a public tabular dataset
bundled with scikit-learn (`sklearn.datasets.load_breast_cancer`),
originally from the UCI Machine Learning Repository.

- 569 rows, 30 numeric features, 1 binary target (`diagnosis`)
- Target: `0` = malignant, `1` = benign
- Task type: binary classification

## Setup Instructions

1. Install Python 3.11+
2. Create and activate a virtual environment:
   ```
   python -m venv .venv
   source .venv/bin/activate    # on Windows: .venv\Scripts\activate
   ```
3. Install dependencies:
   ```
   pip install -r requirements.txt
   ```

## How to Run

```
python src/data_loader.py     # loads the dataset and saves it to data/raw/
python src/inspect_data.py    # prints a first-look inspection report
```

## Progress Log

- **Day 1:** Set up project structure, virtual environment, and Git repo.
  Loaded the dataset with `src/data_loader.py` and saved it to
  `data/raw/breast_cancer.csv`. Ran a first inspection with
  `src/inspect_data.py`: 569 rows, 31 columns, no missing values, no
  duplicate rows, target classes are 357 benign / 212 malignant
  (mildly imbalanced).
- **Day 2:** Cleaned the data with `src/data_cleaning.py` — re-verified
  there are no missing values or duplicates (none found, so no rows
  were dropped) and added a readable `diagnosis_label` column. Ran
  `src/eda.py` to generate 4 visualizations (minimum required was 3),
  saved to `outputs/figures/`:
  - `class_balance.png` — 357 benign vs 212 malignant cases (mild imbalance)
  - `boxplot_mean_radius.png` — malignant tumors have a clearly higher
    median radius and wider spread than benign ones
  - `histogram_mean_texture.png` — malignant cases skew toward higher
    texture values, though the two classes overlap somewhat
  - `correlation_heatmap.png` — `mean radius`, `mean perimeter`, and
    `mean area` are strongly correlated with each other (expected,
    they all measure tumor size) and all three are strongly negatively
    correlated with `diagnosis` (i.e. larger tumors tend to be malignant)
- **Day 3:** Split the data 80/20 (stratified, since classes are
  imbalanced) with `src/train.py`, and trained **two** baseline models
  for comparison (bonus feature):
  - Logistic Regression, wrapped in a scikit-learn `Pipeline` with
    `StandardScaler` (bonus feature: preprocessing pipeline)
  - Random Forest (200 trees)

  Evaluated both with `src/evaluate.py`. **Malignant was treated as
  the positive class** for precision/recall/F1, since missing a
  malignant case is the clinically costlier mistake:

  | Model | Accuracy | Precision | Recall | F1 |
  |---|---|---|---|---|
  | Logistic Regression | 0.9825 | 0.9762 | 0.9762 | 0.9762 |
  | Random Forest | 0.9561 | 0.9512 | 0.9286 | 0.9398 |

  Logistic Regression won on every metric, missing only **1 malignant
  case out of 42** in the test set (Random Forest missed 3). Saved a
  confusion matrix for each model and a feature-importance chart
  (bonus feature) for Random Forest — the top predictors are all
  tumor size/shape measurements (`worst perimeter`, `worst area`,
  `worst concave points`), which agrees with the Day 2 correlation
  heatmap.

  **Conclusion:** Logistic Regression is the better model here — it's
  simpler, more interpretable, and has higher recall on the class
  that matters most. Next steps to improve further: cross-validation
  instead of a single split, hyperparameter tuning with
  `GridSearchCV`, and trying additional models (SVM, Gradient
  Boosting) to close the malignant-recall gap even more.

  A full 2-page write-up (objective, results, challenges faced and
  how they were solved, conclusion) is in `reports/week1_report.docx`.

## Known Limitations

- The target classes are mildly imbalanced (357 benign / 212
  malignant). Addressed via stratified splitting and by reporting
  precision/recall/F1 alongside accuracy rather than relying on
  accuracy alone.
- Metrics come from a single train/test split rather than
  cross-validation, so they carry some sampling variance — noted as
  a next step in the final report.
- Models use default/lightly-tuned hyperparameters; no
  hyperparameter search was performed (also noted as a next step).
